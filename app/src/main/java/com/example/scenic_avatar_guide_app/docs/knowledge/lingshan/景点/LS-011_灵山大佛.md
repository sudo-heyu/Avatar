# 灵山大佛

- **景点ID**：LS-011
- **所属景区**：灵山胜境
- **具体位置**：祥符禅寺北侧，秦履峰南侧，矗立在景区最高处，是整个灵山胜境的核心地标，可俯瞰整个景区及太湖风光。
- **建筑/景观参数**：佛像高88m（主体高度79m+莲花瓣高度9m），含台基总高101.5m，耗铜量达725吨，由1560块6-8毫米厚的铜壁板拼装而成（不含莲花座），焊缝总长度达35公里，铜板面积约9000多平方米，相当于一个半足球场大小。
- **核心功能**：佛教朝圣、祈福景观、核心地标，既是灵山胜境的标志性景观，也是信徒朝拜、游客祈福的核心场所。
- **文化内涵**：灵山大佛是"五方五佛"格局中的"东方大佛"，与香港天坛大佛、四川乐山大佛、山西云冈大佛、河南龙门大佛共同构成中国佛教五大佛像格局。右手施无畏印（除却众生痛苦），左手施与愿印（赐予众生欢乐），216级登云道暗合佛教108烦恼与108愿望，分为两段，前段108级为"烦恼尽除"，后段108级为"愿望圆满"。
- **详细介绍**：灵山大佛是释迦牟尼佛青铜立像，佛体坐落于无锡马山秦履峰南侧，南面太湖，北倚灵山，左挽青龙山，右牵白虎山，环境幽美，风水绝佳。1994年奠基，1997年11月15日落成开光。大佛严格按照佛经如来三十二形相的记载铸造，佛像形态庄严圆满，安详凝重而细致，显现佛陀慈悲的法相。大佛双目垂视，眼神睿智慈祥，不论游客靠近或走远，似乎都在大佛眼神的关切之中；并且随着人的靠近或远离，眼睛仿佛在微微开合，靠得愈近，眼睛就睁得愈开。莲花座共有四层莲瓣组成，每层二十二片莲花瓣，共计有八十八片莲花瓣，凡捐资满人民币一百万元者，可以在其中一片莲花瓣上刻上自己的名号。在大佛座基的裙房里，特地设置两台电梯，专门送信众和游客登上莲花座，走到大佛脚前抚摸佛脚，并称之为抱佛脚。登上216级登云道后是灵山佛教文化博览馆。
- **游玩亮点**：登顶抱佛脚，俯瞰太湖全景，感受大佛宏伟气势；在不同角度拍摄大佛，尤其是在夕阳西下时，金色阳光洒在大佛身上，佛光普照，美不胜收；体验"临时抱佛脚"的趣味与虔诚。
- **演艺/开放信息**：随灵山胜境开放时间（8:00-17:00，冬季闭馆时间提前至16:30），登云道全天开放，佛脚处需要乘坐电梯，游客量大时需排队。
- **备注**：景区标志性景观，被誉为"东方大佛"，是世界上最高大的露天青铜释迦牟尼立像之一；登云道共216级，分为7个平台，前108级寓意消除108种烦恼，后108级寓意圆满108种愿望。
