# 数字人表情说明文档

本文档记录所有 Live2D 表情的用途、特点和视觉参数。

---

## 表情体系概览

表情共 13 个，分为 5 个层次：

| 层次 | 表情 | 用途 |
|-----|------|------|
| 基础态 | neutral | 默认状态 |
| 积极层 | happy、excited、welcoming、approving | 正面情绪表达 |
| 交互层 | thinking、playful、focused | 交互状态 |
| 特殊层 | concerned、apologetic、reverent | 特殊情感 |
| 情感层 | surprised、grateful | 强烈情感 |

## 详细说明

### 1. 中性 (NEUTRAL)
- **用途**：默认状态、无明显情绪
- **触发场景**：空闲等待、正常交流的基础表情
- **视觉特点**：仅保留基础呼吸效果，所有特征参数为 0
- **参数**：仅 ParamBreath = 0.15

### 2. 愉悦 (HAPPY)
- **用途**：开心、满意、轻松愉快
- **触发场景**：正面回答、好消息、愉快交流
- **视觉特点**：
  - 眉毛上扬并微弯（ParamBrowY=1.0, Form=0.3）
  - 眯眼微笑（ParamEyeSmile=1.5）
  - 脸颊泛红（ParamCheek=1.2）
  - 嘴角上扬（ParamMouthForm=1.0）
- **与其他区别**：比 excited 温和，没有夸张的眼睛和发饰动作

### 3. 兴奋 (EXCITED)
- **用途**：热情、激动、期待
- **触发场景**：介绍精彩景点、推荐、表达热情
- **视觉特点**：
  - 眉毛高扬（ParamBrowY=1.3）并左右偏移
  - 大眼微笑（ParamEyeOpen=0.5, Smile=1.2）
  - 脸颊明显泛红（ParamCheek=1.3）
  - 嘴巴较大张开（ParamMouthOpenY=0.8）
  - 发饰和呆毛摆动
- **与愉悦区别**：更夸张、更有活力、有发饰动画

### 4. 欢迎 (WELCOMING)
- **用途**：热情迎客、开场问候
- **触发场景**：游客到达、开场白、主动问候
- **视觉特点**：
  - 眯眼微笑（ParamEyeSmile=1.3）
  - 脸颊泛红（ParamCheek=1.1）
  - 嘴角上扬并微张（ParamMouthForm=0.9, OpenY=0.35）
  - 头发和发饰微动
- **与愉悦区别**：更侧重迎客感，有头发动画

### 5. 赞许 (APPROVING)
- **用途**：认同、肯定、赞许
- **触发场景**：表示同意、肯定游客选择、鼓励
- **视觉特点**：
  - 眉毛微上扬（ParamBrowY=0.5）
  - 微笑（ParamEyeSmile=0.5）
  - 眼睛半闭（ParamEyeOpen=-0.2）
  - 脸颊微红（ParamCheek=0.4）
- **与其他区别**：表情温和收敛，表达"好的/对的"的感觉

### 6. 思考 (THINKING)
- **用途**：思考状态、回忆、考虑
- **触发场景**：回答复杂问题、"让我想想"
- **视觉特点**：
  - 眉毛不对称（左上右下）
  - 眼睛半闭（ParamEyeOpen=-0.15）
  - 眼球向左上看（ParamEyeBallX=-0.5, Y=-0.5）
  - 呆毛微动
- **独特性**：唯一眼球明显偏移的思考表情

### 7. 俏皮 (PLAYFUL)
- **用途**：调侃、轻松、幽默
- **触发场景**：开玩笑、轻松话题、俏皮话
- **视觉特点**：
  - 眉毛严重不对称（左高右低）
  - 眼睛一大一小（ParamEyeOpen: 左=-0.4, 右=0.4）
  - 眼球偏移（ParamEyeBallX=0.5）
  - 歪嘴笑（ParamMouthForm=0.9）
  - 呆毛明显摆动
- **独特性**：最不对称的表情，调皮感

### 8. 专注 (FOCUSED)
- **用途**：认真聆听、专注状态
- **触发场景**：听游客说话、认真观察
- **视觉特点**：
  - 眉毛微上扬（ParamBrowY=0.3）
  - 眼睛睁大（ParamEyeOpen=0.4）
  - 眼球略向下看（ParamEyeBallY=0.1）
  - 表情认真
- **与其他区别**：不笑，表达认真专注

### 9. 关切 (CONCERNED)
- **用途**：担心、关心、关切
- **触发场景**：游客遇到问题、表达关心
- **视觉特点**：
  - 眉毛担忧形（ParamBrowAngle: 左=1.2, 右=-1.2）
  - 眼球下看（ParamEyeBallY=0.2）
  - 嘴角下垂（ParamMouthForm=-0.3）
- **与歉意区别**：关切是担心他人，歉意是自责

### 10. 歉意 (APOLOGETIC)
- **用途**：道歉、愧疚、不好意思
- **触发场景**：服务不周、表达歉意
- **视觉特点**：
  - 眉毛下垂（ParamBrowY=-0.2）
  - 眉毛担忧形
  - 眼睛半闭（ParamEyeOpen=-0.3）
  - 眼球向左下看
  - 嘴角明显下垂（ParamMouthForm=-0.5）
- **与关切区别**：更消极、有自责感、过渡时间更长

### 11. 庄重 (REVERENT)
- **用途**：敬畏、肃穆、庄重
- **触发场景**：介绍宗教场所、庄重话题
- **视觉特点**：
  - 表情收敛、不笑
  - 眼球向上看（ParamEyeBallY=-0.3）
  - 嘴微抿（ParamMouthForm=-0.15）
- **独特性**：最收敛的表情，表达敬畏

### 12. 惊叹 (SURPRISED)
- **用途**：惊讶、惊喜、惊叹
- **触发场景**：介绍壮观景点、意外发现
- **视觉特点**：
  - 眉毛高扬（ParamBrowY=1.2）
  - 眼睛睁大（ParamEyeOpen=0.8）
  - 嘴巴微张（ParamMouthOpenY=0.3）
  - 脸颊微红（ParamCheek=0.5）
- **独特性**：过渡快、眼睛最大

### 13. 感恩 (GRATEFUL)
- **用途**：感谢、欣慰、感动
- **触发场景**：游客感谢、表达感激
- **视觉特点**：
  - 眉毛上扬（ParamBrowY=0.6）
  - 微笑（ParamEyeSmile=0.6）
  - 眼睛半闭（ParamEyeOpen=-0.3）
  - 脸颊明显泛红（ParamCheek=1.0）
- **与愉悦区别**：更内敛、有感动感

## 使用建议

### 1. 表情选择原则
- **根据内容情感选择**：正面内容用积极层，负面内容用特殊层
- **考虑语境**：同样是"好"，可能是赞同或告别
- **配合动作使用**：表情与动作搭配效果更佳

### 2. 表情与动作搭配建议

| 场景 | 推荐表情 | 推荐动作 |
|-----|---------|---------|
| 欢迎游客 | welcoming | welcome_gesture |
| 介绍景点 | excited/happy | point_forward/guide |
| 回答问题 | happy/approving | nod |
| 表示歉意 | apologetic | bow |
| 思考问题 | thinking | thinking_pose |
| 表达惊叹 | surprised | look_up |
| 认真倾听 | focused | listen |

### 3. 过渡时间说明
- **快速过渡 (0.2-0.3s)**：excited、playful、surprised — 情绪变化快
- **中速过渡 (0.3-0.4s)**：happy、welcoming、approving、focused — 自然变化
- **慢速过渡 (0.5-0.6s)**：thinking、reverent、concerned、apologetic — 情绪沉淀

### 4. 避免的问题
- 避免表情频繁切换，会显得不自然
- 消极表情使用要适度
- 表情强度可通过 expressionIntensity 调节
