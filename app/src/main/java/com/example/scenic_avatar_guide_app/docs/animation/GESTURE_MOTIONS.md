# 数字人动作说明文档

本文档记录所有 Live2D 动作的用途、特点和视觉效果。

> **注意**：动作文件中设置的参数值与实际视觉效果有差异，实际角度约为设置值的 40%-60%。

## 详细说明

### 1. 点头 (NOD)
- **用途**：表示同意、确认、回应游客问题
- **触发场景**：回答"是的"、"好的"、"没问题"等肯定性内容
- **视觉特点**：平滑的点头动作，配合身体微微前倾，自然流畅
- **与其他动作区别**：幅度适中，比示意动作的低头更深，但没有欠身的恭敬感

### 2. 摇头 (SHAKE)
- **用途**：表示否定、不同意、拒绝
- **触发场景**：回答"不是"、"没有"、"不行"等否定性内容
- **视觉特点**：头部左右摆动，眼球跟随视线
- **与其他动作区别**：唯一明确左右摆头的动作

### 3. 致意 (WAVE)
- **用途**：日常问候、轻快打招呼、回应
- **触发场景**：见面、离场前的简单问候
- **视觉特点**：头部略仰并右歪，配合眨眼，亲切友好
- **与其他动作区别**：轻快简洁，与欢迎的隆重感形成对比

### 4. 欢迎 (WELCOME_GESTURE)
- **用途**：隆重欢迎、首次见面、景区开场介绍
- **触发场景**：游客刚进入、开场白
- **视觉特点**：明显低头配合身体前倾，眉毛上扬，热情大方
- **与致意区别**：更隆重、有仪式感、时间更长、有身体参与

### 5. 看左 (POINT_LEFT)
- **用途**：引导游客看向左侧景物
- **触发场景**：介绍左侧景点、回答"左边有什么"
- **视觉特点**：头部左转并前低，眼球看向左下，观察探索感

### 6. 看右 (POINT_RIGHT)
- **用途**：引导游客看向右侧景物
- **触发场景**：介绍右侧景点、回答"右边有什么"
- **视觉特点**：头部右转并前低，眼球看向右下，观察探索感

### 7. 示意 (POINT_FORWARD)
- **用途**：介绍前方景物、"请看这里"
- **触发场景**：指向展品、介绍前方景点
- **视觉特点**：头部前低，眼球向右下看，有引导感
- **与引导区别**：指向近处，引导指向远处方向

### 8. 欠身 (BOW)
- **用途**：表示敬意、感谢、道歉、道别
- **触发场景**：感谢游客、道歉、结束服务
- **视觉特点**：深度鞠躬，配合耸肩和呼吸，稳重优雅
- **与欢迎区别**：更恭敬谦逊，没有热情感

### 9. 沉思 (THINKING_POSE)
- **用途**：思考状态、回忆、考虑问题
- **触发场景**：回答需要思考的问题、"让我想想"
- **视觉特点**：头部仰起，右歪，眼球上看，眉微扬
- **独特性**：唯一明显仰头的动作

### 10. 引导 (GUIDE)
- **用途**：方向指引、"请往那边走"
- **触发场景**：指路、引导游客前往某处
- **视觉特点**：头部右转，身体侧转配合，有明确的指向性
- **与示意区别**：指向远处方向，有身体参与

### 11. 仰望 (LOOK_UP)
- **用途**：看高处景物、表达惊叹或敬畏
- **触发场景**：介绍高大的景点、表达震撼
- **视觉特点**：头部后仰，眼球上看，身体微后倾
- **与沉思区别**：仰望是看高处，沉思是思考状态；仰望有身体后倾

### 12. 聆听 (LISTEN)
- **用途**：认真听讲、表示关注
- **触发场景**：游客提问时、认真倾听
- **视觉特点**：头部右转并前低，右歪，身体侧倾，专注感
- **与看右区别**：聆听有前低和歪头，表达专注听；看右是观察

## 动作分类

### 按头部垂直方向分类
| 类别 | 动作 | 特点 |
|-----|------|------|
| 低头类 | 点头、欢迎、示意、欠身、聆听 | 表示恭敬、关注、引导 |
| 平视类 | 摇头、致意、看左、看右、引导 | 正常交流、观察 |
| 仰头类 | 沉思、仰望 | 思考、惊叹 |

### 按身体参与程度分类
| 类别 | 动作 | 特点 |
|-----|------|------|
| 仅头部 | 摇头、致意、看左、看右、示意 | 轻量级动作 |
| 头+身体 | 点头、欢迎、欠身、沉思、引导、仰望、聆听 | 更有表现力 |

## 参数说明

### 头部与身体参数

| 参数 | 说明 | 典型范围 |
|------|------|---------|
| angleX | 头部左右旋转 | -28° ~ 28° |
| angleY | 头部俯仰（正值=下巴向上） | -20° ~ 45° |
| angleZ | 头部侧倾 | -18° ~ 15° |
| bodyAngleX/Y/Z | 身体旋转 | -12° ~ 12° |
| shoulder | 肩膀动作 | -1.0 ~ 1.0 |

### 眼球方向参数（v2.1 新增）

| 参数 | 说明 | 典型值 |
|------|------|--------|
| eyeBallX | 眼球左右 | -1.0（左）~ 1.0（右） |
| eyeBallY | 眼球上下 | -1.0（上）~ 1.0（下） |

**当前支持眼球跟随的动作**：
- `POINT_LEFT`：eyeBallX = -1.0（眼球向左看）
- `POINT_RIGHT`：eyeBallX = 1.0（眼球向右看）
- `LOOK_UP`：eyeBallY = 1.0（眼球向上看）

眼球方向在动作过渡时会被平滑插值，与头部参数同步渐变。

## 使用建议

1. **避免频繁重复同一动作**：动作之间应有间隔，避免机械感
2. **根据内容选择动作**：肯定用点头，否定用摇头，介绍用示意/引导
3. **注意动作时长**：较长动作（欢迎、欠身）适合重要场合
4. **配合表情使用**：动作与表情搭配效果更佳
5. **眼球跟随增强指向感**：point_left/right 时眼球同步偏移，引导效果更好
