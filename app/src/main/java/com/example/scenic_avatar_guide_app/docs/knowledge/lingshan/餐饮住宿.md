## 三、餐饮住宿实用信息

### 用餐建议
1. **午餐时间**：11:30-13:30为最佳用餐时间
2. **避开高峰**：用餐高峰可能排队，建议错峰
3. **提前预约**：节假日建议提前预约

### 住宿建议
1. **提前预订**：旺季建议提前1-2周预订
2. **位置选择**：景区内住宿可享无限次入园
3. **含门票套餐**：购买住宿+门票套餐更划算
4. **退房时间**：一般为12:00前

### 特别体验
- **灵山精舍早课**：6:30，诵经/静坐（住客专属）
- **免费体验**：部分住宿含禅修、抄经活动
- **VIP通道**：景区内酒店住客有专属入园通道
