# 拈花塔

- **景点ID**：NH-007
- **所属景区**：拈花湾禅意小镇
- **具体位置**：香月花街北段，拈花广场东侧，拈花堂北侧，是香月花街的制高点，也是拈花湾小镇的标志性建筑。
- **建筑/景观参数**：唐风木结构楼阁式五重塔，四方五层，由须弥座台基、塔身、塔刹三部分组成；总高27.98米，塔身高21.28米，塔刹高6.7米；塔刹由覆钵、仰莲、相轮、华盖、三花蕉叶、宝珠、刹链、风铎等组成，黄铜铸就，外贴金箔；直棱窗棂、重唇板瓦、转角斗拱、蜀柱斗子等彰显唐风古韵；塔有东南西北四门，不可攀登。
- **核心功能**：禅意地标、文化景观、视觉焦点，核心作为拈花湾小镇的标志性建筑，展示唐风建筑美学，同时是夜间亮塔仪式的核心表演场地。
- **文化内涵**：以"拈花微笑"禅宗典故命名，象征"以心传心、豁然开朗"的禅意境界。塔身古朴庄重，融合传统、和风与禅意，是香月花街乃至整个拈花湾的精神象征。
- **详细介绍**：拈花塔是拈花湾小镇主街区——香月花街的最高点，也是整个景区的标志性建筑。塔为唐风木结构楼阁式佛塔，四方五层设计，出檐深远，尽显盛唐气象。塔身采用传统木构技术，直棱窗棂、重唇板瓦、转角斗拱等细节古朴典雅。塔刹为黄铜铸造并贴金箔，在阳光下熠熠生辉。白天，游客可在塔下广场拍照打卡，穿一身汉服与唐风建筑相映成趣；塔顶可俯瞰整个拈花湾，白墙黛瓦的街巷蜿蜒曲折，梵天花海色彩斑斓，远处的太湖波光粼粼。夜晚，亮塔仪式开启是拈花湾最震撼的表演之一。
- **游玩亮点**：白天登高俯瞰小镇全景；与拈花塔汉服合影，定格唐风禅意大片；夜晚观赏亮塔仪式，感受灯光与禅乐的完美融合；拍摄塔身与夜景灯光的同框美照。
- **演艺/开放信息**：开放时间随拈花湾小镇（9:00-21:30，冬季提前至20:30）；亮塔仪式演出时间约18:30-20:50，每半小时一场，每场约5分钟；周五、周六加演。
- **备注**：拈花湾标志性建筑，不可攀登；亮塔仪式是景区夜间必看演出，建议提前10分钟到塔前广场占位；塔身周围禁止触摸、攀爬。
