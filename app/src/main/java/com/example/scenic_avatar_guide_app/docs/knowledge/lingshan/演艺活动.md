# 演艺活动

## 一、九龙灌浴

### 基本信息
| 项目 | 内容 |
|-----|-----|
| **地点** | 菩提大道北端，景区中轴线核心位置 |
| **演出形式** | 大型音乐动态群雕 |

### 演出内容
依据《本行经》中释迦牟尼诞生的传说：
- 莲花铜雕缓缓绽放
- 太子佛像从莲花中升起并自转
- 九条飞龙同时喷水沐浴佛身
- 配合专属音乐《佛之诞》

### 演出时间
| 时段 | 场次 | 备注 |
|-----|-----|-----|
| **平日** | 10:00、11:30、13:30、15:00 | 每日4场 |
| **周末/节假日** | 增加演出场次 | 以景区广播通知为准 |

### 演出时长
约15分钟

### 游玩贴士
- 建议提前10分钟到场占位
- 表演结束后可接取龙头流出的"圣水"
- 周边设有休息区

## 二、《吉祥颂》演出

### 基本信息
| 项目 | 内容 |
|-----|-----|
| **地点** | 灵山梵宫圣坛 |
| **演出形式** | 270°沉浸式实景演绎 |
| **演出规模** | 可容纳2000人同时观演 |

### 演出内容
- 演绎释迦牟尼悟道成佛的故事
- 运用全息投影、水雾等现代科技
- 结合真人表演与声光电效果
- 展现佛法的智慧与慈悲

### 演出时间
| 时段 | 场次 |
|-----|-----|
| **上午** | 10:35、11:30 |
| **下午** | 14:00、16:00 |

### 演出时长
约20分钟

### 票务信息
- **普通门票不含**：需另购演出票50元/人
- **6周岁以下或70周岁以上**：演出票需另购50元

### 游玩贴士
- 建议提前30分钟排队入场
- 节假日可能加演1-2场
- 以景区广播与官方小程序通知为准
