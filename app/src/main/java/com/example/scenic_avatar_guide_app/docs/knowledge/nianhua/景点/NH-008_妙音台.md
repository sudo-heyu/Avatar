# 妙音台

- **景点ID**：NH-008
- **所属景区**：拈花湾禅意小镇
- **具体位置**：香月花街南端，五灯湖北侧，拈花堂南侧，处于拈花湾小镇的核心演艺区域。
- **建筑/景观参数**：传统中式戏台建筑风格，砖木结构，飞檐翘角；台口立柱楹联"慧眼见一切，妙音满十方"；上场门和下场门分别题有"来兮"、"归去"；戏台面积适中，舞台开阔，适合表演展示。
- **核心功能**：禅意戏台、文化演艺、戏曲体验，核心用于展示中国传统戏曲文化与禅文化的融合，为游客提供观赏禅意表演、体验戏曲艺术的场所。
- **文化内涵**：以"妙音"为名，寓意佛法的智慧之音能够传遍十方，与楹联"慧眼见一切，妙音满十方"相呼应。"来兮"、"归去"的门楣题字，将戏台小天地、天地大戏台的传统戏剧文化与禅文化巧妙融合，使人感慨，耐人回味，体现"人生如戏、戏如人生"的禅意哲学。
- **详细介绍**：妙音台是灵山小镇·拈花湾的传统禅意戏台，完美融合了中国传统戏曲文化与禅宗文化。戏台建筑采用中式传统风格，飞檐翘角、古朴典雅，与拈花湾的整体唐风氛围相协调。台口楹联"慧眼见一切，妙音满十方"点明禅意主题，寓意智慧的佛眼观照万物，美妙的法音传遍十方。上场门"来兮"与下场门"归去"的设计，巧妙地将传统戏曲"出将入相"的台口文化与禅宗"来去自如、放下执念"的理念相结合，游客在此不仅能观赏到昆曲、京剧等传统戏曲表演，还能感受到禅意与戏曲艺术的深度交融，是体验中国传统文化的绝佳场所。
- **游玩亮点**：观赏传统戏曲表演，感受禅意与戏曲的融合；品读楹联文化，体会"来兮归去"的禅意哲学；与古风戏台合影，定格禅意文化瞬间；参加戏台互动体验活动。
