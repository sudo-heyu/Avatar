# 演艺活动

## 一、《禅行》沉浸式夜游

### 基本信息
| 项目 | 内容 |
|-----|-----|
| **类型** | 沉浸式行进式夜游演艺 |
| **创作团队** | G20文艺晚会核心团队 |
| **地位** | 第四届世界佛教论坛闭幕式献礼级巨制 |

### 演出特点
- 集观赏、互动、体验、巡游于一体
- 以行进式方式穿越四大地标景点
- 现代数字多媒体技术与舞台表演艺术结合
- 游客既是鉴赏者，也是体验者和参与者

## 四、演出时间查询

### 查询方式
1. **官方小程序**：微信搜索"拈花湾"→首页"节目演艺"
2. **景区公告**：入园后查看电子屏幕
3. **游客中心**：咨询工作人员

### 温馨提示
1. **提前占位**：《禅行》演出建议提前30分钟到达观赏区域
2. **关注天气**：雨天部分室外演出可能调整
3. **错峰观赏**：周末节假日人流较大，可选择工作日或晚场
4. **住客特权**：景区内酒店住客可能有专属观赏区域
